# Momenteschenker Mobilität Installer

Öffentlicher Proxmox-LXC-Installer für **Momenteschenker Mobilität**.

Die Anwendung selbst liegt in einem privaten Repository. Der Installer erstellt einen Debian-13-LXC mit DHCP, installiert Docker und lädt eine freigegebene Anwendungsversion mit einem temporär eingegebenen, read-only GitHub-Token.

> Status: frühe Entwicklung. Noch nicht produktiv verwenden.
